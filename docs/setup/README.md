# Setup & Getting Started

This directory contains guides for setting up and getting started with the KAMBRIQ Terraform infrastructure.

## Contents

- **[TERRAFORM_USAGE.md](./TERRAFORM_USAGE.md)** - Complete guide on how to use this Terraform repository, including deployment steps for shared, dev, and prod environments.
- **[ROUTE53_DNS_SETUP.md](./ROUTE53_DNS_SETUP.md)** - Guide for configuring Route53 nameservers in your domain registrar to enable DNS validation for SES and ACM certificates.
- **[ACM_SES_MANUAL_SETUP.md](./ACM_SES_MANUAL_SETUP.md)** - Guide for manually creating and configuring ACM certificates and SES identities in AWS Console, then providing ARNs to Terraform via terraform.tfvars.
